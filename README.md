# 🔮 Arcana Mystic - Tarot Oracle 78

เว็บแอปพลิเคชันดูดวงไพ่ยิปซี 78 ใบ ธีมแฟนตาซี ทำงานด้วยระบบกระจายไพ่หมุนวนรอบศูนย์กลาง พร้อมระบบสั่งการด้วยกล้องตรวจจับท่าทางมือ (Hand Gesture Detection) ผ่านเทคโนโลยี MediaPipe

---

## 🌟 ฟีเจอร์หลัก (Features)

- **78 Tarot Cards Database:** รองรับข้อมูลไพ่ยิปซี 78 ใบ แสดงผลชื่อภาษาอังกฤษ ภาษาไทย และคำทำนาย
- **Fantasy UI & Custom Fonts:** ตกแต่งสไตล์แฟนตาซีลึกลับ ใช้ฟอนต์ `Cinzel Decorative` สำหรับหัวข้อภาษาอังกฤษ และ `Prompt` สำหรับภาษาไทย
- **Spread Animation:** ไพ่กระจายตัวออกเป็นวงกลมโดยตัวไพ่ไม่เอียง และหมุนวนรอบศูนย์กลางเพื่อสุ่ม
- **Hand Gesture Control:**
  - ✋ **แบมือ (Open Hand):** สั่งเริ่มกระจายไพ่และหมุนวน
  - ✊ **กำมือ (Fist):** สั่งหยุดไพ่และสุ่มเลือกไพ่ทันที
- **Responsive Pop-up Modal:** แสดงผลรายละเอียดไพ่พร้อมคำทำนายในหน้าต่างแบบ Blur Overlay
