# 🔮 Mystic Tarot - คุณหมีร่ายเวทมนตร์ (Full Documentation)

เว็บแอปพลิเคชันดูดวงเสี่ยงทายไพ่ยิปซี (Tarot Card Reader) สไตล์มินิมอลเวทมนตร์ ทำงานบนเว็บเบราว์เซอร์ 100% โดยไม่ต้องพึ่งพา Backend หรือไฟล์ Media ภายนอก รองรับทั้งระบบสัมผัส (Touch/Click) และระบบตรวจจับท่าทางมือผ่านกล้อง (Gesture Control) พร้อมเอฟเฟกต์ภาพและเสียงสังเคราะห์สุดตระการตา

---

## 📸 ภาพรวมของระบบ (System Overview)

ระบบถูกออกแบบภายใต้คอนเซปต์ **"Minimal Magic & Smooth Motion"** โดยเน้นความคมชัด อ่านง่าย สมดุล และมีความเสถียรสูง:
- **UI/UX สมดุล มินิมอลแบบหนา**: ใช้ฟอนต์ `Noto Sans Thai` (ความหนาระดับ Medium 500 ถึง Semi-Bold 600) เพื่อความชัดเจน ตัดกับโทนสีมืดมิดของอวกาศ และกรอบกระจกใส (Glassmorphism)
- **Full-Screen Elliptical Carousel**: การหมุนวนสุ่มไพ่ 3 มิติกระจายโค้งเต็มหน้าจอตามเข็มนาฬิกา เพิ่มความตื่นตาตื่นใจขณะร่ายเวท
- **Web Audio API**: สร้างเสียงสังเคราะห์เวทมนตร์ประกายวิบวับ (Magic Chime) และเสียงไพ่หมุนพึ่บพั่บโดยตรงจากเบราว์เซอร์ แก้ปัญหาไฟล์เสียงโหลดไม่ติด
- **Smart Gesture Detection**: ตรวจจับท่าทางมือด้วย MediaPipe Hands แบบเสถียร แม่นยำ ไม่รวนเมื่อเอามือลง

## 🌟 ฟีเจอร์เด่น (Key Features)

### 1. หน้าแรกตอบรับสมดุล (Setup Screen)
- ระบบสอบถามความสมัครใจก่อนเปิดกล้อง: *"ต้องการร่ายเวทมนต์กับคุณหมีหรือไม่"*
- ปุ่มเลือก **"ต้องการ"** (เปิดกล้องตรวจจับมือ) หรือ **"ไม่เป็นไร"** (ใช้งานระบบสัมผัส/คลิก)
- การจัดวางองค์ประกอบตรงกลางอย่างสมดุล ละมุนสายตา

### 2. อนิเมชันวงรีไพ่หมุนเต็มจอ 3D (Full-Screen Ellipse Carousel)
- ขณะร่ายเวท สำรับไพ่ 10 ใบจะกระจายตัวออกเป็นวงรีกว้างเต็มหน้าจอ (Viewport Relative)
- การคำนวณพิกัด Trigonometry $(x = r_x \cdot \cos\theta, y = r_y \cdot \sin\theta)$ พร้อมปรับค่า `scale` และ `z-index` ตามมิติลึก-ตื้น
- เสียงสังเคราะห์การสับไพ่ประกอบการหมุนวนที่นุ่มนวล

### 3. ระบบตรวจจับท่าทางมือที่เสถียร (Stable Gesture Recognition)
- **กล้องทำงานอยู่เบื้องหลัง**: ไม่แสดงช่องกล้องขึ้นมารบกวนสายตาบนหน้าจอ
- **Hold Confirmation (กำมือค้าง 0.4s)**: ป้องกันปัญหามือกระตุก หรือการสุ่มลั่นเองโดยไม่ตั้งใจ
- **ไม่มีมือ = นิ่งสงบ**: หากเอามือลง หรือไม่มีมือปรากฏในเฟรม กล้องจะเข้าสู่สถานะสแตนด์บายโดยไม่รบกวนการทำงานของระบบ
- **ข้อความ Badge อัปเดตสอดคล้อง**: แสดงไอคอนและสถานะบนแถบ Badge ด้านบนอย่างตรงไปตรงมา

### 4. ตัวละครน้องหมีและฉากดวงดาว 3D
- น้องหมีเวทมนตร์ SVG โบกคทาพร้อมประกายดาววิบวับขณะสลับไพ่
- พื้นหลังดวงดาวลอยล่องในอวกาศแบบ 3D Perspective (HTML5 Canvas)
